# الباحث الحديثي — اردو، عربی (Al-Bahith Al-Hadithi — Salafi Urdu & Vocalized Arabic Edition)

**منہجِ سلف صالحین کے عین مطابق `https://hadeeth.com/` کا مکمل اے-ٹو-زیڈ (A-to-Z) ہو بہو اردو و عربی تحقیقی پلیٹ فارم**

یہ منصوبہ **«علمی معاون پروجیکٹ»** کے تحت `https://hadeeth.com/` (نقایہ) کے مکمل فرنٹ اینڈ، بیک اینڈ، فوری تلاش انجن، ۵ تحقیقی فلٹرز، انٹرایکٹو شجرۂ اسانید، جرح و تعدیل اور تمام ۴۵+ علومِ حدیث شعبہ جات کو **`الباحث القرآني (اردو، عربی)`** کے معیاری آرکیٹیکچر اور **`ریختہ و قاری اردو-عربی لغت`** کے ذخیرے کے ساتھ یکجا کر کے تیار کیا گیا ہے۔

## ۲۔ منہجِ سلف صالحین کے آہنی ضوابط (Strict Salafi Urdu Standards)

اس پلیٹ فارم کے ہر ترجمے، شرح، عنوان اور انٹرفیس میں عقیدہ و ادب کے درج ذیل اصول نافذ کیے گئے ہیں:
- اسمائے الٰہیہ کے لیے صرف **اللہ، اللہ تعالیٰ، اللہ عزوجل، رب العالمین** استعمال کیا گیا ہے (غیر شرعی عجمی الفاظ سے مکمل اجتناب)۔
- نبی کریم کے اسمِ گرامی کے ساتھ ہمیشہ **ﷺ** اور ادب و اطاعت کے لیے **محبت، تعظیم اور اتباع** کے الفاظ۔
- صحابہ کرام کے لیے **سیدنا / سیدہ / ام المومنین ... رضی اللہ عنہ / عنہا / عنہما / عنہم**۔
- ائمۂ محدثین و تابعین کے لیے **امام / حافظ / علامہ ... رحمہ اللہ (المتوفیٰ ...ھ)** اور انتقال کے لیے صرف **وفات**۔

## ۴۔ دو سطحی فولڈر اور فائل اسٹرکچر (Dual-Tier Project Architecture)

### الف) لوکل پی سی رن ٹائم (`"D:\علمی معاون پرجیکٹ\حدیث سرچ"` — صرف `~16.5 MB`):
- `backend/main.py` و `backend/cloud_storage_bridge.py` — کلاؤڈ برج + تیز رفتار FastAPI سرور + Exact `search.hadeeth.com` v2 Wire API + SvelteKit `/__data.json` Devalue Bridge
- `backend/arabic_urdu_sanitizer.py` — اردو و عربی سرچ کلینر، ۱۴۰+ اصطلاحی کراس لنگوئل اسٹیمر اور FTS5 بلڈر
- `backend/static/` — اصل `https://hadeeth.com/` کا ۱۰۰٪ ہو بہو کمپائلڈ Svelte 5 + SvelteKit 2 فرنٹ اینڈ بنڈل (`index.html`, `assets/sk/immutable/*`, `fonts/`, `assets/hadeeth_urdu_bridge.js`, `assets/hadeeth_urdu_bridge.css`)
- `pipeline/` — سلفی اردو و پروٹوکول انجن (`salafi_urdu_engine.py`, `sveltekit_bridge.py`, `normalizer.py`, `books_catalog.py`)
- `database/catalogs/hadeeth_home_catalogs.json` و `database/local_runtime_cache.db` — پری پیکڈ فلٹر کیٹلاگز (`<15ms` اسٹارٹ اپ) اور مختصر مقامی کیشے
- `tools/` — `setup_local_pc_minimal.py`، `sync_to_gdrive.py` اور ۱۵ مراحل پر مشتمل `verify_platform.py`

### ب) گوگل ڈرائیو کلاؤڈ والٹ (`G:\My Drive\علمی پروجیکٹ\حدیث سرچ\cloud_data` — `3.25 GB`):
- `cloud_data/database/al_bahith_hadith.db` — ۱.۷۱ جی بی ماسٹر SQLite + FTS5 ڈیٹا بیس (`journal_mode=DELETE`، لاک فری)
- `cloud_data/datasets_raw/` — ۳۳ خام علمی ذخائر (`1.49 GB`: ریختہ لغت، درر السنیہ، صحاح ستہ، موسوعۃ الاحادیث، تراث، جرح و تعدیل)
- `cloud_data/exports/` — PostgreSQL سیڈ اور RAG JSONL ایکسپورٹس
- `cloud_data/dev_archive/` — ڈوکر، اسکیما، بلڈ اسکرپٹس اور فرنٹ اینڈ آرکائیو
